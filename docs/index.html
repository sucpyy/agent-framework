LOCAL FIRST · MULTI AGENT WORKSPACE

把复杂任务，放进一个清晰的工作台。

Agent Framework 是在本机运行的多智能体工作台。用自然语言发起任务，跟踪规划、工具调用和执行结果；代码、调研和办公工具在同一界面协作。

02 / GET STARTED

在本机启动

需要 Python 3.10+。下面是 Windows PowerShell 示例；安装后也可以双击 启动.bat。

git clone https://github.com/sucpyy/agent-framework.git
cd agent-framework
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py

访问 http://127.0.0.1:8000。首次登录使用 admin / admin123。未配置模型密钥时为 Echo 模式；在工作台系统设置中填写模型密钥后才能执行真实模型任务。

当前版本没有修改初始管理员密码的界面，只适合受信任的本机环境。请勿把本地服务直接暴露到公网。
03 / ARCHITECTURE

四类智能体，各司其职

用户请求 → FastAPI / WebSocket
↓
快速通道 / 规划器 / 调度器
↓
通用
研究 / 代码
办公
↓
结果汇总 → 对话与执行概览

快速通道由通用智能体处理；复杂任务可以拆分后调度研究、代码和办公智能体。文件与命令工具使用同一工作区根目录，减少路径混乱。

后端采用 FastAPI、WebSocket 和 Python；前端使用原生 HTML、CSS 和 JavaScript。完整代码结构、工具列表与测试命令见 仓库 README。
